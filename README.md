# jet — downloads

Prebuilt binaries for **jet**, a self-contained package manager for bad networks.
No Node, no runtime dependencies — one executable.

> This repository holds **release binaries only**. The source is maintained privately.
> Site: https://jet.kim

## Install

**macOS / Linux**

```sh
curl -fsSL https://github.com/y6861977-ui/jet-dist/releases/latest/download/install.sh | sh
```

**Windows (PowerShell)** — download `jet-windows-x86_64.exe` from the
[latest release](https://github.com/y6861977-ui/jet-dist/releases/latest), then run it
from a terminal: `jet help`.

## Downloads

Every release ships:

| Platform | Asset |
|---|---|
| Windows x64 | `jet-windows-x86_64.exe` |
| macOS (Apple Silicon) | `jet-darwin-arm64` |
| macOS (Intel) | `jet-darwin-x86_64` |
| Linux x64 | `jet-linux-x86_64` |
| Linux ARM64 | `jet-linux-aarch64` |

Verify integrity against `SHA256SUMS` in the same release.
